# TUI File Manager with Markdown Viewer

Текстовый пользовательский интерфейс (TUI) для навигации по файловой системе с возможностью просмотра файлов, подсветкой синтаксиса и поддержкой Markdown с оглавлением (TOC).

## Возможности

- 📁 **Навигация по файловой системе** - просмотр директорий и файлов
- 📄 **Просмотр файлов** - поддержка различных форматов файлов
- 🎨 **Подсветка синтаксиса** - для Go, Python и других языков программирования
- 📖 **Markdown поддержка** - рендеринг Markdown файлов с красивым форматированием
- 📑 **Оглавление (TOC)** - для быстрой навигации по заголовкам Markdown
- 🎯 **Два режима работы**:
  - Файловый менеджер (`F`)
  - Режим документа с TOC (`T`)
- 👻 **Скрытые файлы** - возможность показа/скрытия скрытых файлов (`.`)

## Управление
### Основные клавиши

- ↑ / ↓ - перемещение по списку файлов или TOC
- → - открыть файл/директорию (в TOC - перейти к заголовку)
- ← - вернуться на уровень выше
- . - показать/скрыть скрытые файлы
- ? - показать/скрыть справку
- Ctrl+Q - выход из программы
- Ctrl+P - показать путь к текущему файлу

Режимы работы
- T - переключиться в режим документа (показать TOC для Markdown файлов)
- F - переключиться в режим файлового менеджера
Навигация в TOC
- ↑ / ↓ - перемещение по оглавлению
- Enter или → - перейти к выбранному заголовку
- Esc - вернуться к просмотру файла

Поддерживаемые форматы
- Текстовые файлы - обычный текст
- Markdown (.md) - с полной поддержкой рендеринга и TOC
- Go (.go) - с подсветкой синтаксиса
- Python (.py) - с подсветкой синтаксиса
- Другие файлы - отображаются как обычный текст

### Интерфейс
Программа разделена на две основные панели:

- Левая панель - файловый менеджер или оглавление (TOC)
- Правая панель - просмотр содержимого файла

Активная панель подсвечивается розовой рамкой.

### Особенности
- Адаптивный интерфейс - автоматически подстраивается под размер терминала
- Асинхронный рендеринг - Markdown рендерится без блокировки интерфейса
- Плавная навигация - интеллектуальный скроллинг списков
- Поддержка Unicode - корректное отображение широких символов

### Разработка
Проект написан на Go и использует современные подходы к созданию TUI-приложений. Архитектура основана на модели MVU (Model-View-Update) из библиотеки Bubble Tea.
