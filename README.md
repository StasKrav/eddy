# Go TUI File Explorer & Editor

Консольный файловый менеджер и редактор текста на Go, построенный на базе [Bubble Tea](https://github.com/charmbracelet/bubbletea) и связанных библиотек (`bubbles`, `lipgloss`, `glamour`).

Программа работает в терминале и позволяет просматривать директории, открывать файлы, редактировать текст и переключаться в режим предпросмотра Markdown.

---

## 🚀  Возможности

- Две панели: 
  - **левая** — дерево файлов/папок  
  - **правая** — редактор или предпросмотр  
- Поддержка Markdown-предпросмотра через `glamour`
- Подсветка активной панели
- Управление только с клавиатуры
- Создание и удаление файлов
- Работа со скрытыми файлами (`.`)
- Всплывающее окно справки

---

## ⌨️  Горячие клавиши

| Клавиша         | Действие |
|-----------------|----------|
| ↑ / ↓           | перемещение по списку файлов |
| →               | открыть файл / войти в директорию |
| ←               | вернуться в родительскую директорию |
| .               | показать / скрыть скрытые файлы |
| **Ctrl+N**      | создать новый файл |
| **Ctrl+D**      | удалить файл |
| **Ctrl+S**      | сохранить файл |
| **Tab**         | переключить редактор ↔ предпросмотр |
| **Ctrl+← / →**  | переключение активной панели |
| ?               | показать / скрыть справку |
| Esc             | отмена действия / выход |
| **Ctrl+Q**      | выйти из программы |

---

## 🛠  Установка и запуск

```
git clone https://github.com/StasKrav/eddy.git
cd eddy
```
Установить зависимости:
```
go mod tidy
```
Просто запустить:
```
go run main.go
```
Собрать и запустить:
```
go build -o editor
./editor
```
